# prompts/

Reusable prompt snippets for Paradise Chat. Drop a `.md` file here per recurring instruction so it
can be pasted/referenced instead of retyped. Project-local — travels with the repo.

Suggested starters (create as needed):
- `pr-description.md` — house style for PR bodies.
- `commit-style.md` — Conventional Commits conventions used here.
- `review-checklist.md` — what to check before merging (auth flow, WS/REST payload parity, etc.).
