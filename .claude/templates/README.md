Scaffolding templates for Paradise Chat — code and doc starters Claude can copy when creating new
files. Project-local; no external dependency.

Suggested starters (create as needed):
- `drf-viewset.py.tmpl` — DRF viewset + serializer matching this repo's patterns.
- `zustand-store.js.tmpl` — Zustand store skeleton matching `frontend/src/stores/`.
- `consumer-handler.py.tmpl` — `ChatConsumer.handle_*` + matching `group_send` event shape.
