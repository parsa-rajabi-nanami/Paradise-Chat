# Tailwind Design System

Production-ready component patterns written *in Tailwind CSS*. This skill is the implementation
layer; abstract token modeling (primitive→semantic→component) belongs to the `design-system` skill.

## Use this skill when

- Configuring `tailwind.config.js` theme/extend
- Building component variants with Tailwind utility classes
- Implementing responsive layouts and breakpoint patterns
- Setting up class-strategy dark mode and color schemes
- Standardizing accessible Tailwind UI patterns across the frontend

## Do not use this skill when

- Designing the token architecture/CSS-variable layers → use `design-system`
- Writing React component logic/state → delegate to the `frontend-developer` agent
- The task is backend/Django, slides, branding, or non-Tailwind CSS frameworks
