# Use Paradise Chat

This guide explains how to create an account, start conversations, send messages, manage rooms, and protect your account. You do not need programming knowledge to use these steps.

## Create an account

Open the Paradise Chat website and select **Sign up**. Enter these values:

- **Email address**: The email used to sign in
- **Username**: At least three characters using letters, numbers, or underscores
- **Display name**: Optional name shown to other people
- **Password**: At least eight characters with an uppercase letter, a lowercase letter, and a number
- **Security passphrase**: At least 16 characters. Keep it private because the service uses it for sign-in and sensitive account actions

Select **Create account**. The service signs you in after registration when registration is enabled by the administrator.

## Sign in and sign out

Select **Sign in** and provide your email, password, and security passphrase. The application refreshes a short-lived access session while you use it. Select the account menu and sign out when you finish on a shared device.

## Start a conversation

From the chat page, select the control for a new conversation:

1. Choose **Direct** to contact one person
2. Search for at least two characters of their username or display name
3. Select the person to open the conversation

To create a group:

1. Choose **Group**
2. Enter a group name
3. Search for and select at least two people
4. Add an optional description
5. Select **Create group**

The service returns you to the new room after it creates the conversation. A direct room cannot have room settings changed. Group owners and admins can edit group information.

## Send and manage messages

Type a message and send it from the message box. The chat updates in real time when the connection is available. The interface also shows typing indicators, online status, and read state when those events arrive.

You can edit or delete your own text messages. Deleted messages remain as a deletion notice so conversation history stays consistent. A message can contain text, an attachment, or both.

## Send an attachment

Use the attachment control next to the message box. The service accepts these file types:

- JPEG, PNG, and WebP images
- PDF, TXT, DOC, DOCX, XLS, and XLSX documents
- ZIP archives

Each attachment can be up to 10 MB. The service checks both the filename and file content. If an administrator disables uploads, the attachment control cannot complete the request.

Attachments are private to active participants. Do not share a copied attachment URL with someone who is not a room participant because the service checks authentication and room membership for every download.

## Manage a group

Open group settings from the room menu. Owners and admins can update the group name, description, and avatar. They can search for users and add members.

Roles control member management:

| Role | Permissions |
| --- | --- |
| Owner | Edit room settings, add members, remove members, and change member roles |
| Admin | Edit room settings, add members, and remove regular members |
| Member | Chat and leave the room |

An admin cannot remove an owner or another admin. An owner cannot change another owner's role or remove another owner. Owners should transfer responsibility before leaving a group that needs to remain active.

## Use subgroups

An owner can create a subgroup under a group. Subgroup members must belong to the parent group, and the parent group must remain active. The sidebar shows nested rooms with indentation so you can distinguish a subgroup from its parent.

## Update your account

Open **Settings** to update your display name, username, biography, avatar, email notifications, and push notification preference. Use the password section to change your password or security passphrase. Provide the current password and current passphrase when the form asks for them.

Account deletion is permanent for your account identity and removes private attachments. The service preserves conversation history without your account identity where possible. Confirm the action only after exporting anything you need.

## If something does not work

- **The page does not load**: Refresh the page and confirm that the service URL is correct
- **Messages do not appear**: Check your connection, refresh the page, and sign in again if the access session expired
- **A file is rejected**: Confirm the type is allowed and the size is no more than 10 MB
- **You cannot add someone**: Ask an owner or admin to add you, or confirm that the person is not already in the room
- **You cannot change group settings**: Ask the owner for the admin role or request that the owner make the change
- **Sign-in is temporarily blocked**: Wait for the login rate limit window to expire, then try again

Contact the service administrator with the time of the problem, the room or action involved, and a screenshot that does not expose passwords, passphrases, tokens, or private message content.
